ABOUT THIS PROJECT

Technology, made approachable.

TechWorld is a learning project exploring modern technologies and the cloud infrastructure behind a real web application.

What powers TechWorld?

Python and Flask serve the application, Amazon RDS stores content, and an Application Load Balancer distributes traffic to EC2 instances managed by an Auto Scaling Group across Availability Zones.

CloudWatch collects metrics and application logs. Alarms can notify operators through Amazon SNS.
