# AWS CloudOps Platform

A hands-on AWS infrastructure and operations portfolio project.

## Objectives

- Build secure and reliable AWS infrastructure using Terraform.
- Practice AWS networking, IAM, monitoring, and incident response.
- Implement cost controls and operational runbooks.
- Document architecture, troubleshooting, and recovery procedures.

## Planned Stack

- AWS
- Terraform
- AWS CLI
- Git and GitHub
- Amazon CloudWatch and CloudTrail

## Project Status

Phase 0: Local tooling and AWS account preparation.

No application infrastructure has been deployed yet.

## Cost and Security

- Monthly budget alert target: $10 USD.
- Verify estimated costs before deploying resources.
- Never commit credentials, secrets, or Terraform state.
